# Consumer AI Tool Consumption & Engagement

## Project Overview

This project uses Tableau to explore patterns in AI tool usage and engagement within a student-focused dataset. It examines preferred AI tools, usage patterns, academic streams, device preferences, trust in AI tools, and reported academic impact.

The aim is to transform the dataset into clear, interactive visualisations that make patterns and comparisons easier to explore.

## Objectives

- Explore the distribution of preferred AI tools.
- Examine daily AI usage patterns.
- Compare usage and preferences across academic streams and study years.
- Investigate willingness to pay for AI access.
- Explore reported trust in AI tools and academic impact.

## Tools Used

- **Tableau:** Data visualisation and dashboard development
- **CSV:** Dataset format
- **GitHub:** Project files, documentation, and collaboration

## Dataset

The project uses `Students.csv`, containing fields related to AI tool preferences, usage hours, academic stream, study year, devices, awareness, trust, and reported academic impact.

The supplied dataset contains 3,614 records and 16 columns. These records should not be interpreted as 3,614 unique students because the student-name field contains repeated values.

## Dashboard Plan

1. **AI Adoption Overview:** Record counts, preferred AI tools, average daily usage, willingness to pay, and academic-stream distribution.
2. **Student Demographics:** Academic streams, study years, preferred-tool comparisons, and device distribution.
3. **Usage & Engagement:** Daily usage patterns, awareness, and comparisons across student groups.
4. **Trust & Academic Impact:** Trust ratings, reported grade impact, professor permissions, and willingness to pay.

## Important Note

The findings describe patterns in the supplied dataset. The dataset's provenance and representativeness should be verified before making claims about real-world student populations.
